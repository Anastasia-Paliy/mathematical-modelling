# Математическое моделирование

В данном репозитории представлена коллекция классических математических моделей, реализованных в рамках учебной дисциплины

## Содержание

### 1. СТАТИЧЕСКИЕ МОДЕЛИ
*   **1.1. Производственная функция Кобба-Дугласа**
*   **1.2. Модель Леонтьева**

### 2. АНАЛИЗ ДИНАМИЧЕСКИХ МОДЕЛЕЙ
*   **2.1. Модель Солоу**
*   **2.2. Модели распространения инфекционных заболеваний**
    *   2.2.1. Модель SIR
    *   2.2.2. Модель SEIR
    *   2.2.3. Модель SEIRD
    *   2.2.4. Модель SEIRD + вакцинация
*   **2.3. Модель Лотки-Вольтерра**
*   **2.4. Модель взаимодействия двух конкурирующих видов**
*   **2.5. Аттрактор Лоренца**

### 3. МОДЕЛИРОВАНИЕ ФИЗИЧЕСКИХ СИСТЕМ
*   **3.1. Двойной математический маятник**
*   **3.2. Связанные пружинные маятники**
*   **3.3. Маятник Фуко**
*   **3.4. Симпатические маятники**

### 4. ДИНАМИЧЕСКИЕ МОДЕЛИ ЭКОНОМИКИ
*   **4.1. Модель Самуэльсона-Хикса**
*   **4.2. Двухсекторная модель экономики**
    *   4.2.1. Модель двухсекторной закрытой экономики
    *   4.2.2. Взаимодействие двух экономик
*   **4.3. Трёхсекторная модель экономики**

### 5. МОДЕЛИ С РАСПРЕДЕЛЁННЫМИ ПАРАМЕТРАМИ
*   **5.1. Модель распространения тепла в однородном тонком стержне**
    *   5.1.1. Явная разностная схема. Метод сеток
    *   5.1.2. Неявная разностная схема. Метод прогонки
*   **5.2. Уравнение колебания струны**
*   **5.3. Двумерное волновое уравнение. Колебание мембраны**
